# Exam Generator & Corrector

A no-login web app that generates OMR-scannable math exams (weighted by
grade/area) and grades photographed answer sheets automatically, plus a
companion Android app for grading from a phone camera.

## What's in here

- `backend/` - Flask web app: Exam Generator + Exam Corrector, question
  bank, PDF rendering, and the OMR grading engine.
- `mobile/` - Flutter app source (`lib/main.dart` + `pubspec.yaml`). The
  `android/`/`ios/` platform folders are generated by CI, not checked in.
- `.github/workflows/build-apk.yml` - builds the Android APK on every push
  to `mobile/` and publishes it to the repo's "latest" GitHub Release.

## Scope

Only Cycle 2 (General track: G5-G8) and Cycle 3 (Advanced + General
tracks: G9-G12) are supported, per the school's math-area weighting
table. Cycle 1 and every Applied/Elective track are intentionally out of
scope. The question bank has 20 questions per math area per cycle (240
total), auto-generated with parametrized templates so every exam draws a
fresh, non-repeating set.

## Running the backend

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 question_bank_gen.py   # only needed once, to (re)build data/question_bank.json
python3 app.py                 # serves http://localhost:5000
```

Open `http://localhost:5000` for the Exam Generator, `/corrector` for the
Exam Corrector. No login, no external services required.

### How grading works

Every generated exam records the exact printed position of each answer
bubble (`exam_pdf.py`). To grade a photo of a completed sheet,
`omr_corrector.py` detects the 4 black corner squares printed on the
page, computes a perspective transform back to that exact layout, then
samples darkness at each known bubble position -- rather than guessing
with generic circle detection. This is robust to a sheet photographed at
an angle, rotated, or slightly skewed, as long as all 4 corners are
visible.

## Mobile app

The Flutter app lets a teacher pick a previously generated exam, photograph
each page of a student's sheet, and get the same grading result as the
web app. It only ships `lib/` and `pubspec.yaml`; CI runs `flutter create`
to regenerate the Android project scaffold before building, so there's
nothing else to set up locally beyond having Flutter installed if you
want to run it yourself:

```bash
cd mobile
flutter create --platforms=android .
flutter pub get
flutter run
```

The APK is built automatically by GitHub Actions and published to this
repo's "latest" release; the web app's "Download App (APK)" button links
directly to that release asset.
